# Build Rule

프로젝트 코드를 수정하거나 빌드 작업을 수행할 때 아래의 지침을 엄격하게 따르십시오.

- 빌드 시 오류 없도록 하고 오류가 발견되면 다시 검증하는 방식으로 진행해.
- 이런 식으로 반복이 5번이상이 되면 중지하고 반복이 시작될 때마다 반복 횟수를 맨 앞에 기록해.


## PWA 개발 필수 가이드라인
PWA의 특성을 고려해 **"캐시가 꼬일 수 있으니 꼭 기존 앱을 완전히 삭제하고 설치하셔야 합니다"**라고 처음부터 명확히 가이드 하세요.
