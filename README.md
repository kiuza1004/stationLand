# StationLand (스테이션랜드) 🚇

> **서울 지하철 정차역 실시간 점령 및 50자 네온 전광판 웹앱 게임**  
> 🔗 **웹 바로 실행 주소 (GitHub Pages)**: **[https://kiuza1004.github.io/stationLand/](https://kiuza1004.github.io/stationLand/)**  
> 📦 **GitHub 소스 저장소**: [https://github.com/kiuza1004/stationLand](https://github.com/kiuza1004/stationLand)

별도의 서버 설치 없이 위 **웹 바로 실행 주소**를 클릭하면 모바일/PC 웹 브라우저에서 즉시 플레이할 수 있습니다!  
지하철을 타고 이동하면서 정차역마다 간단한 제동 타이밍 미니 미션을 수행하여 정차역을 점령하고, 일정 시간 동안 **최대 50자(헤드라인 15자 + 상세 35자)**의 응원 문구, 유머, 또는 로컬 개인 광고를 게시하는 실시간 지하철 땅따먹기 게임입니다.

## 🌟 핵심 특징 및 아키텍처

### 1. 비용 0원 & 무(無)데이터베이스 인메모리 엔진
* **외부 DB 0개**: 무거운 DB(MySQL, Firebase 등) 없이 단일 Node.js 서버 메모리(RAM)에 약 1~2MB 크기의 전체 지하철 역 상태를 유지하여 1만 명이 접속해도 병목 없이 초고속으로 작동합니다.
* **원자적 3중 백업 시스템 (`Atomic Write`)**: 
  * 1분마다 `data/station_state.tmp.json` 작성 후 원자적으로 교체하여 서버 돌발 종료 시에도 백업 파일 깨짐 방지.
  * 서버 종료 신호(`SIGINT`, `SIGTERM`) 감지 시 Graceful Shutdown으로 마지막 상태 즉시 저장 및 서버 재시작 시 오프라인 시간 경과 자동 보정 복구.
* **10초 스냅샷 메모리 캐싱**: 1만 명이 매초 서버를 두드려도 실제 서버 조회는 10초에 1번만 일어나며, CDN 무료 캐싱 헤더가 지원됩니다.

### 2. 무(無)로그인 & 익명 보안 토큰
* 회원가입 없이 브라우저 접속 즉시 고유 익명 UUID와 서버 HMAC 서명 토큰을 발급받아 바로 플레이할 수 있습니다.
* **기기 변경 복구 코드**: 캐시 삭제나 스마트폰 변경 시 내 포인트, 닉네임, 문구 프리셋을 암호화 코드로 안전하게 내보내고(Export) 불러올(Import) 수 있습니다.
* **시크릿 창 어뷰징 방지**: 최소 2개 역 이상 이동(체크인)이 확인된 승객에게만 정식 점령 및 공감 권한을 부여합니다.

### 3. 독점 방지와 공평한 순환 룰 (1만 명 규모 밸런스)
* **슬롯 다층화**: 서울 지하철 330개 역을 상·하행 플랫폼 및 메인 전광판(1석), 서브 전광판(3석), 혼잡역 1~10호차 슬롯으로 분산.
* **3분 절대 보호막**: 역 점령 직후 3분 동안은 절대 무적으로 문구 노출이 보장됩니다.
* **보호 중 타 유저 참여**: 보호막이 켜져 있어도 다른 유저가 미션을 깨면 현재 점령자의 방어막(Shield)을 깎거나 대기열에 이름을 올리고 포인트를 획득합니다.
* **골든 타임 & 2시간 과열 방전**: 30분 연속 점령 유지 시 **15분 골든타임(황금 네온 무적)**이 발동되며, 종료 직후 슬롯이 방전되어 **기존 점령자는 향후 2시간 동안 재점령이 금지**되어 모든 승객에게 점령 기회가 순환됩니다.

### 4. 50자 네온 전광판 UI & 공감 경제
* **[헤드라인 15자] + [상세 문구 35자] 2단 분리 (총 50자)**: 글자가 빽빽해지지 않고 전문 광고 배너처럼 세련된 타이포그래피 대비를 유지합니다.
* **공감(❤️ 좋아요) 연장**: 지나가는 다른 승객이 문구를 보고 공감을 누를 때마다 점령 시간이 **+15초 연장**되고 방어막이 수리됩니다.
* **50자 프리셋**: 출퇴근 이동 중 빠르게 점령할 수 있도록 사전 문구 3~5개를 등록해 두고 원터치로 등록할 수 있습니다.

### 5. 가상 연습 모드 vs 실전 GPS 모드 분리
* **🎮 가상 연습 모드**:
  * 실제 지하철에 탑승하지 않아도 가상 시뮬레이터로 다음 역 이동 및 10초 제동 미니게임 연습, 샌드박스 점령을 자유롭게 테스트할 수 있습니다.
  * 가상 모드에서 등록된 문구는 `[연습]` 태그가 붙어 구분됩니다.
* **📍 실전 GPS 모드**:
  * 실제 서울 지하철 탑승 승객을 위한 실전 모드입니다.
  * 스마트폰 HTML5 GPS(위치 정보)를 실시간 추적하여 현재 내 위치와 정차역 좌표 간의 거리를 계산합니다.
  * **반경 800m 이내(지하철 역사 및 승강장 범위)**로 접근했을 때만 정차역 체크인 및 전광판 점령이 허용되며, 다른 위치에 있을 경우 체크인이 원천 차단됩니다.
* **🗺️ 최신 지하철 노선도 인터랙티브 맵 뷰**:
  * 2호선 순환선 및 주요 환승 노선망을 한눈에 볼 수 있는 SVG 인터랙티브 노선도를 제공합니다.
  * 노선도에서 원하는 역을 터치하면 해당 역의 실시간 전광판 카드로 자동 스크롤/포커스되며, GPS 모드 시 내 위치 근처 역에 레이더 핑 애니메이션이 표시됩니다.

## 🚀 빠른 시작 가이드 (로컬 실행)

### 사전 요구사항
* Node.js v18 이상 (Node.js v24 권장)
* npm

### 실행 방법
```bash
# 1. 의존성 패키지 설치
npm install

# 2. 서버 실행
npm start
```

서버가 시작되면 웹 브라우저에서 아래 주소로 접속합니다:
👉 **`http://localhost:3000`**

```
stationLand/

│   ├── index.html             # 모바일 PWA 웹앱 메인 화면
│   ├── css/
│   │   └── style.css          # 사이버 네온 지하철 전광판 다크 테마
│   ├── js/
│   │   ├── app.js             # UI 컨트롤러 및 스냅샷 폴링
```
